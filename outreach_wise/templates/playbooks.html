One file per playbook

Export one to share it on GitHub, or import someone else's. The block between the +++ lines is the settings; everything under it is the instructions the AI follows.

  • input: the lead column the AI starts from, and which sources to fetch.
  • fields: what it writes. Each one becomes a variable like ai_hook.
  • checks: rules checked automatically before you review (length, banned phrases, links).
  • Instructions: plain Markdown. Your guide, rules and example emails.
+++
name = "YouTube creators"
language = "auto"

[input]
column = "channel_url"
sources = ["youtube_channel"]

[fields.hook]
describe = "One concrete thing from their channel"
max_words = 60

[fields.subject]
describe = "Personal, tied to the hook"
alternatives = 3

[checks]
email_words = [60, 150]
banned = ["quick question"]
+++

# Instructions
Write to YouTube creators about …
